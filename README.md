# Это проект банковского виджета, который позволяет производить различные операции над входными данными

## Функционал:

1. masks.py содержит функции маскировки номера счёта и номера карты клиента банка:
    - Является вспомогательным файлом
    - функция get_mask_card_number маскирует 16-значный номер карты в формате XXXX XX** **** XXXX. Обрабатывает символы, начиная с конца строки.
    - функция get_mask_account маскирует 20-значный номер счёта в формате **XXXX. Обрабатывает символы, начиная с конца строки.
2. widget.py содержит в себе:
    - А) функцию mask_account_card, обрабатывающую входную информацию одного из двух типов:
    - имя карты и её номер. Принимает на вход строку, например: "Visa Platinum 1234567890123456", "Мир 1234567890123456" 
    - тип счёта и его номер. Принимает на вход строку, например: "Счёт 12345678901234567890"
    - Использует для этого функции из модуля masks.py
    - Б) функцию get_date, принимающую на вход строку в формате ISO 8601, и возвращающий дату в формате строки "DD.MM.YYYY"  
3. processing.py содержит в себе:
    - А) Функция filter_by_state, которая фильтрует банковские ID по статусам. На вход принимает список словарей (содержит информацию о клиентах банка) и необязательный параметр сортировки, имеющий одно из двух знаечений: 'EXECUTED' (по-умолчанию) или 'CANCELED' (параметр, который может указать пользователь).
    - Б) Функция sort_by_date, которая сортирует банковские ID по дате. На вход принимает список словарей (содержит информацию о клиентах банка) и необязательный параметр сортировки (По-умолчанию сортирует в обратном порядке. Для сортировки в прямом порядке, в качестве второго параметра указывается строка 'False').

## Использование:

1. Клонируйте репозиторий следующей командой:

    `git clone git@github.com:shadowfang7025/sky-coding.git`

2. Дополните основной модуль widget.py строками, соответствующими Вашей задаче.
